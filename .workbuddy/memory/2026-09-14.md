## 完成：运行 AppApplication 并修复报错（后端）

搭建本地构建环境并实际跑通 Spring Boot 应用（Task #5）。

### 修复 1：3 个编译错误（同一模式）
`Result.success(data, page, total)` 的泛型由 `data` 推导，而 `result.getContent()` 返回 `List<T>`，但方法声明写的是 `Result<Page<T>>`，导致类型不兼容：
- `controller/project/ProjectController.java:43` → 改为 `Result<List<Project>>`，补 `import java.util.List`
- `controller/employee/EmployeeController.java:42` → 改为 `Result<List<Employee>>`，补 `import java.util.List`
- `controller/payroll/PayrollController.java:47` → 改为 `Result<List<PayrollOrder>>`（已有 List 导入）

修复后 `mvn compile` BUILD SUCCESS（265 个源文件，仅 1 个 WebMvcConfig 过时 API 警告）。

### 修复 2：Swagger UI 500
`application-dev.yml` / `application-test.yml` 中 `springdoc.api-docs.enabled: false` 与 `swagger-ui.enabled: true` 矛盾——api-docs 关闭导致 springdoc 未注册静态资源，访问报 `NoResourceFoundException`。→ 两处均改为 `enabled: true`。修复后 `/swagger-ui/index.html` 与 `/v3/api-docs` 均 200。

### 修复 3：端口冲突
不指定端口时应用绑定到 53575，而该端口被 WorkBuddy 进程占用 → `Web server failed to start. Port 53575 was already in use`。→ 运行时显式加 `--server.port=8080`。
